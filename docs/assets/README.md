# Изображения документации

[← На главную](../../README.md) · [Стенд интерфейса](../development.md#mock)

| Файл | Содержание |
| :--- | :--- |
| `cover.svg` | Обложка на основе существующего знака `web/public/favicon.svg`. |
| `publication-light.png` | Раздел публикации, светлая тема, сценарий `idle`. |
| `creatives-light.png` | Уникализация фотографий и превью, светлая тема. |
| `accounts-dark.png` | Таблица аккаунтов, тёмная тема, сценарий `idle`. |
| `mobile-light.png` | Открытая папка библиотеки на узком экране, светлая тема. |

Снимки показывают реальный интерфейс из сборки клиента. Все аккаунты,
прокси и результаты берутся из `dev/_ui_mock.py` и являются вымышленными.
Для обновления соберите интерфейс в отдельном каталоге, запустите стенд
с `--ui web/dist` и снимите соответствующие экраны в headless-браузере.
Проверьте отсутствие ошибок, загрузочных состояний и личных данных.

Не используйте живой профиль, настоящее состояние приложения или ключ API
для иллюстраций. Сохраняйте исходный знак продукта и читаемые подписи `alt`
в документах, которые ссылаются на изображения.
