# Интерфейс программы (web/)

React 19 + TypeScript + Vite + Tailwind 4 + shadcn/ui (Base UI). Сервер
программы (`main.py`) отдаёт собранный интерфейс и API на одном адресе.

```
npm install
npm run dev          # http://127.0.0.1:5173, /api -> API_TARGET (по умолчанию 127.0.0.1:8740)
npm run build:app    # сборка в ../ui — туда, откуда отдаёт сервер (её же зовёт build_exe.py)
npm run build        # сборка в dist/ — только посмотреть, программа её не видит
npm run typecheck && npm run lint && npx vitest run
```

Стенд без живых аккаунтов и прокси — `python dev/_ui_mock.py --port 8799`
(сценарии: `/_mock?scenario=running|waiting|done|idle|empty|clean|error`,
экран пароля: `/_mock?auth=1`, пароль 1234), затем
`API_TARGET=http://127.0.0.1:8799 npm run dev`.

Пустое имя сценария (`/_mock?scenario=`) стенд отбивает ошибкой 400: это
опечатка, текущий сценарий и вход остаются. `auth=` без значения ничего не
меняет — пароль ставят и снимают только `auth=1` и `auth=0`.

Отдельный набор — случай отметок прокси: `/_mock?proxies=mixed|empty|dead|checking`.
`mixed` — один проверенный, один мёртвый и два непроверенных; `dead` — мёртвы
все; `checking` — три строки проверяются, четвёртый уже мёртв; `empty` — список
пуст при включённом тумблере. Смена сценария возвращает прокси на `mixed`, кроме
`empty`: там тумблер выключен и список пуст. Незнакомое имя отбивается так же,
как у сценария.

## Где что лежит

| Папка | Что там |
|---|---|
| `src/app/` | каркас: разделы (`sections.ts` — единственный список), меню, нижняя навигация, маршруты, вход по паролю |
| `src/api/` | всё общение с сервером: типы ответов, запросы (TanStack Query), живой поток `stream.ts`, журнал `logs.ts` |
| `src/components/ui/` | кит shadcn — генерируется CLI (`npx shadcn add …`), правится только ради общего поведения |
| `src/components/` | общие компоненты приложения: `Page`/`PageHeader`/`PageBody`, `Panel`, `StateView`/`ErrorView`/`LoadingRows`/`QueryView`, `confirm()`, `NumberInput`/`RangeInput`/`parseNumber`, `FilterChips`, `SearchInput`, `SimpleSelect`, `RejectedLines`, `Stat`/`StatusDot`/`StatusBadge` |
| `src/hooks/` | `useAutosave`, `useHotkey`, `useMediaQuery` |
| `src/lib/` | `format.ts` (числа, даты, склонения), `notify.ts` (тосты), `native.ts` (окно программы, буфер обмена) |
| `src/features/<экран>/` | экран целиком: страница, его компоненты, его состояние. Чужой экран не импортирует внутренности соседа — только его явный контракт |

## Правила

**Код**
- Одно и то же пишется один раз. Прежде чем писать — поищи в `components/`, `hooks/`, `lib/`, `api/`.
- Данные сервера — только через `src/api/`. Живой поток пишет в тот же кэш, что и опрос.
- Подписи и константы экрана — в одном файле экрана (пример: `features/campaign/labels.ts`).
- Никаких `any`, `// @ts-ignore`, `oxlint-disable` без причины в комментарии.

**Вид**
- Темы — системная, светлая и тёмная. Цвета — только токенами (`bg-card`, `text-muted-foreground`, `text-success`, `text-warning`, `text-destructive`, `text-primary`). Никаких hex и `rgb()`.
- Смысловой цвет — у маленького элемента: точки, иконки, числа. Текст целиком не красим.
- Экран = `Page` > `PageHeader` (название, счётчик, действия; главное — последним, `variant="default"`, одно на экран) > `PageBody`.
- Блоки внутри экрана — `Panel`. Пусто, ошибка, загрузка — `StateView`/`ErrorView`/`LoadingRows` (или `QueryView`).
- Шкала отступов Tailwind: между панелями `gap-4`, внутри панели `p-4`, между полями формы `gap-5`, подпись—поле `gap-2`.
- Типографика: заголовок экрана `text-lg font-semibold`, заголовок панели `text-sm font-semibold`, текст `text-sm`, вторичное `text-xs text-muted-foreground`, числа — `tabular`.
- Телефон (<768px): нижняя навигация, всё в одну колонку, цели касания от 40px (кит уже растёт через `pointer-coarse:`), горизонтального скролла страницы нет. Широкое — в свой `overflow-x-auto`.

**Тексты**
- Коротко: подпись поля — одно-два слова, кнопка — глагол. Пояснений под полями и подсказок с описаниями нет — результат действия сообщает тост.
- Тост — законченное предложение с точкой (`notify.ok/info/warn/error`). Длинные списки режутся до трёх строк.
- Термины: публикация, круг, пролито / не пролито / забанено, снято за нарушение правил, очистить посты, вход.

**Клавиатура**
- Alt+1…8 — разделы, Ctrl+B — свернуть меню, Ctrl+F — поиск на экране, Esc — закрыть верхний слой.
- Сочетания — `useHotkey` (по физической клавише, работает на русской раскладке).
- Подтверждение — `await confirm({...})`: у необратимого фокус на «Отмена».
